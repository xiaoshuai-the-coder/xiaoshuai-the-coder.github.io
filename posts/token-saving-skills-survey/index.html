10 万星 Caveman 领衔：五个省 token 的开源 skill，从输出瘦身到上下文换血

xiaoshuai1024 included in AI
About 200 words One minute 
Contents

  • pi-boomerang：过程换摘要，像回旋镖一样扔出去再飞回来
  • planning-with-files：把工作记忆搬到磁盘上
  • claude-token-optimizer：专治「边干边演讲」
  • 文言文.skill：最省钱的语言是最压缩的自然语言
  • 怎么选

Agent 用得狠的都有一笔痛账：一个会话几十万 token，月底看账单血压升高。社区给这个病开出的药方已经成了一个小生态——我按「治哪一段浪费」把 GitHub 上的省 token skill 盘了一遍，挑出五个各有绝活的，star 数全部刚刚经 GitHub API 核实，数据不写印象流。

先建一个判断框架，五个 skill 正好各占一格。agent 的 token 浪费发生在四个环节：说得多（输出冗长）、想得吵（思考独白外溢）、记性差（重复喂上下文）、过程留痕多（长任务的中间步骤全量滞留在窗口里）。挑 skill 先问自己浪费在哪一环。

Caveman：输出瘦身的祖师爷（101,246★）

如果你只装一个，装这个。口号是语法错误级的：「why use many token when few token do trick」——让 agent 用穴居人腔说话，代码、命令、报错保持原样，纯聊天输出砍 65%。

10 万星之后它进化成了全家桶：caveman shrink 压缩命令输出的噪音（字节级可还原），caveman mem 做持久记忆（原始字节可恢复），还有一个 proxy 层在 Claude Code 实测基准里省下 33.2% 的输入 token（官方 54 轮 pinned benchmark）。最有想象力的玩法叫 pixel mode：把 SKILL.md 正文渲染成 PNG 让模型看图——frontmatter 保持文本不影响触发，正文用图读。「每个 skill 都在每次调用时重新加载完整 prompt，这笔税你永远在缴」，它的解法是把税基变成图片。

覆盖 30+ agent，MIT + BSL 双协议。输出冗长是所有人的第一痛点，它也是这个赛道的明星。

pi-boomerang：过程换摘要，像回旋镖一样扔出去再飞回来

长自主任务是吞金兽：修一个登录 bug 读 10 个文件改 5 处跑测试，50k token 起步。297★ 的 pi-boomerang（给 pi coding agent 的 skill）思路是任务照常跑，跑完把原始历史整体换成一份展开式交接摘要——作者管这叫反向 D-Mail：《命运石之门》里 D-Mail 改写世界而观察者保留记忆，boomerang 改写观察者而世界不变，会话树就是你的 Reading Steiner。

玩梗归玩梗，机制扎实：orchestrator 拿到的是自包含的后续回合，中间的 5 万 token 不再滚雪球进主对话。凡有子任务派发机制的 agent 都值得抄这个模式。

planning-with-files：把工作记忆搬到磁盘上

26,381★，卖点就一行：「你的 context 会死，计划不会。」三个文件上磁盘——task_plan.md、findings.md、progress.md，每回合由 hook 重新注入关键状态，/clear、崩溃、compaction 都杀不死它。

省钱逻辑藏在后头：上下文丢了就得重喂背景，重喂是最贵的浪费。带这套文件的新会话平均 5.0 回合恢复现场，裸跑要 13.3 回合；内部基准 96.7% 通过率、盲测 A/B 三胜零负。Manus 式「石头板」工作记忆，60+ agent 可装。上下文频繁丢失的人，这个治本。

claude-token-optimizer：专治「边干边演讲」

108★ 的小而美，扎的是另一个真痛点：agent 干活时把思考过程全念出来——猜歧义、倒冗余代码、解释一堆废话。它的协议套件（Antigravity V1/V2、Ultimate）强迫结构化工程流程替代碎嘴，作者的实测表里省 76%-93%，没有第三方复核，当参考别当承诺。量级小但思路典型：thinking out loud 也是税。

文言文.skill：最省钱的语言是最压缩的自然语言

2★ 但必须收录，因为思路最野：让 AI 用文言文回答，本地 MCP 免费翻回白话——「你看到的是人话，花的是古文的钱」。文言的信息密度天然高于现代汉语，一字千金在这里是字面意思。除了猎奇，它点破了一层：语言选择本身就是压缩算法。顺手一提，我这台机器上还常驻着同思路的 caveman-lite 和 wenyan 输出档。

怎么选

对照四环节收束：说得多→Caveman；过程留痕多→pi-boomerang；记性差→planning-with-files；想得吵→claude-token-optimizer；预算极限/猎奇→文言文.skill。我的组合拳是 Caveman（管输出和读入）加 planning-with-files（管长任务记忆），覆盖了八成日常浪费。

这些 skill 共享同一个底层认知：context 是预算不是空气。每一句冗余输出、每一段滞留的过程记录、每一次重喂的背景，都是没花在刀刃上的预算。工具会把账算得越来越细，而账算细的那一刻，省钱就不再是玄学。

想动手优化自己的 skill 结构，/posts/claude-code-write-your-own-skill/ 里也有分层组织的思路；想动手写自己的第一个 skill，/posts/claude-code-write-your-own-skill/ 是完整教程。
